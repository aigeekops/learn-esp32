# 语法入门文章核对记录

更新日期：2026-10-24。

## 本次零基础读者审阅

文章扩充为 33 节独立入门教程。1—19 节先建立通用编程基础，20 节讲计时，之后进入引脚、传感器、屏幕、网络和完整项目；最后提供练习、课程索引和查阅方法。

本轮集中修正以下跳步：

| 原有问题 | 本轮修改 |
|---|---|
| 编译、框架、库、API 等词直接出现 | 开篇解释作用与运行流程 |
| 尚未理解表达式、类型，就进入硬件公式 | 先讲表达式、数据类型、位与字节、运算与转换 |
| 循环只解释 for 的一个器件例子 | 补齐 while、do...while、switch、break、continue、return 的作用范围 |
| 函数只讲返回值 | 补齐声明/定义、形参/实参、传值/引用、默认参数和重载 |
| 先出现 &Wire，再解释地址 | 指针、引用、类和构造函数放在屏幕驱动之前 |
| String、C 字符串混用 | 解释结束零字符、内容比较与地址比较、转换和有效期 |
| 回调只见匿名函数写法 | 从普通函数名、函数指针讲到 Lambda 与捕获 |
| 计时示例需要先懂按钮和引脚 | 新增只用串口的通用非阻塞示例 |
| 网页代码被统称为浏览器脚本 | 解释 HTML 元素、id、Promise、fetch、async/await、箭头函数和定时刷新 |
| 只判断是否看过说明 | 加入预测题、答案、串口实验与独立编写任务 |
