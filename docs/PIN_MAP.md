# 引脚预算表

日期：2026-10-27。本文由 `src/lessons.ts`（第 1–16 课）与 `src/robot-lessons.ts`（第 17–25 课）的引脚定义导出，是引脚分配的单一真源。改任何一处引脚，都要同步本文与 `docs/CURRICULUM.md` 的接线表。

## 结论先行

ESP32-DevKitC V4 共 24 个可用 GPIO（0/1/3 留给下载与日志）。机器人阶段固定占用 15 个，只剩 8 个（2、5、12、15、21、22、36、39），其中 36/39 只能输入、没有内部上拉。

前 16 课是面包板实验台，目前用到 **13 个机器人引脚**，只有 I²C 的 21/22 是独占的。

因此：**一块板带完 25 课的所有器件在物理上不成立**。实验台需要 LED、按钮、电位器、温度、蜂鸣器、RGB×3、OLED×2、舵机、土壤、钢琴 8 键，至少 20 路 IO，而整块板也只有 24 路，机器人一项就吃掉 15 路。课程显式分成两段接线，并在第 17 课给出迁移检查单。

## 机器人固定引脚表（第 17–25 课）

| 功能 | 引脚 | 备注 |
| --- | --- | --- |
| TB6612 左轮 | 25 PWM / 18 AIN1 / 19 AIN2 | 20 kHz，8 bit |
| TB6612 右轮 | 26 PWM / 23 BIN1 / 27 BIN2 | 第 21 课起接入 |
| 驱动使能 | 4 STBY | 拉低即全停 |
| 编码器左 | 32 A / 33 B | 3.3 V 推挽 |
| 编码器右 | 34 A / 35 B | 3.3 V 推挽；34/35 无内部上拉 |
| 超声波 | 13 TRIG / 14 ECHO | ECHO 经 2.2 kΩ / 3.3 kΩ 分压到约 3.0 V |
| 串口 | 16 RX / 17 TX | UART2，115200 8N1，与日志口分离 |
| 剩余自由脚 | 2、5、12、15、21、22、36、39 | OLED 占 21/22；36/39 仅输入且无上拉 |

合计：15 个固定引脚 + 8 个自由脚。

## 冲突矩阵：实验台 → 机器人

| 实验台器件 | 涉及课次 | 实验台引脚 | 机器人阶段是否回收 |
| --- | --- | --- | --- |
| LED | 2、3、4、6、7、9、15、16、17 | 23 | 是 → 右轮 BIN1 |
| 按钮 | 3、9 | 27 | 是 → 右轮 BIN2 |
| 电位器 | 4、6、9、11、16 | 34 | 是 → 右编码器 A |
| TMP36 | 7、8、14 | 35 | 是 → 右编码器 B |
| 蜂鸣器 | 7、12、16 | 25 | 是 → 左轮 PWM |
| RGB | 5 | 23 / 19 / 18 | 是 |
| 舵机 | 10 | 18 | 是 → 左轮 AIN1 |
| 土壤传感器 | 11、16 | 34 | 是 |
| OLED | 8、11、16 | 21 / 22 | 否，可保留 |
| 钢琴 8 键 | 12 | 13、14、16、17、18、19、26、27 | 是，全部 |

## 迁移检查单：进入第 17 课之前

1. 拔掉 LED 23、按钮 27、电位器 34、温度 35、蜂鸣器 25、RGB 三路、舵机 18、土壤 34、钢琴 8 键的连线。
2. OLED 的 21/22 可以保留，继续显示用。
3. 按课次逐步接：第 17 课超声波 13/14 → 第 18 课 TB6612（25/18/19/4）→ 第 19 课编码器 32/33 → 第 21 课右轮（26/23/27）与右编码器（34/35）→ 第 22 课 UART2（16/17）。
4. 每接一组就烧一次固件再调，不要一次接完再排错。

## 想一块板走到底：三个方案

| 方案 | 做法 | 代价 |
| --- | --- | --- |
| A（默认） | 两段式：实验台 → 机器人，中间做一次迁移 | 需要重接一次线 |
| B | 加 I²C IO 扩展器（MCP23017 / TCA9555，16 路），把钢琴、按钮、灯挪到扩展器 | 多一课扩展器内容；扩展器不能做高速输入 |
| C | 换板：ESP32-S3 / C3 / P4 的 GPIO 更多（ESP32-P4 有 27 个 GPIO） | 需要重新标定引脚与外设映射，课程要改 |

推荐 A 起步；已经有一块 38 脚板又不想重接线的，选 B；打算认真做真机的，直接选 C。
