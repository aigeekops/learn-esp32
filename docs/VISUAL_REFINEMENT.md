# 视觉与交互改版：第一轮

本轮以「认识 ESP32」和「点亮 LED」作为对照验收页，参考 Learn Arduino 的页面比例和操作流程。课程内容、引脚及固件模板保持原有 ESP32 定义。

## 已实现

- 桌面信息栏使用有上限的高度，课程卡片减少窄屏中文碎行。
- 调整相机角度、默认取景、网格、金属及 LED 材质、接线弧度；按实际器件投影范围自动取景，切课和选中器件时平滑移动、旋转和缩放，避开原理图、检查器和工具栏，遵循减弱动画设置。
- 热点标注增加引线、选中态和相互避让。
- LED 与串联电阻分别拾取、检查；点击代码中的电阻值进入电阻检查器。
- LED 颜色使用可键盘操作的色块，修改参数同步代码、场景与原理图。
- 切课时停止模拟、清空日志、回到概览和代码首行，并关闭放大的面板。
- 公众号引导文案为「一起学 AI X 机器人」。全站侧栏增加「极客行动」入口，点击显示用户提供的原始二维码。弹窗可通过关闭按钮、遮罩和 Esc 关闭，关闭后恢复焦点；不主动弹出。
- 二维码作为内嵌资源构建，适用于 Pages 子目录及单文件 HTML，不依赖外部图片服务。

上述共用布局和控件适用于全部课程；其余 14 课尚未逐课完成视觉对照。

## 追加的交互对照修正

- 切课保留开发板，旧导线撤回、旧器件退出，新器件落位后导线逐条从端点接入；快速切课取消前一次组装，减弱动画设置直接完成组装。
- 原理图默认宽度由 220 px 调整为 340 px，增大符号和字号；手机端保持字号并允许纵向滚动。
- 原理图与 3D 场景双向选择，选中高亮和检查器共用状态；GPIO 节点可定位对应的实体引脚。
- 运行时原理图同步 LED、按钮开合和信号电平；参数变更同步原理图、代码与模型。
- 翻页按钮与课程卡片分区，卡片轨道顶部留白显示完整完成标记。

## 面包板落孔修正

- 普通 LED、RGB LED、三路限流电阻与电位器由统一的 2.54 mm 孔位坐标生成引脚和跳线落点。每孔只占用一次；同排 a–e 与 f–j 分别导通，中缝隔离。
- 电阻横跨中缝，跳线与电阻使用同组的不同孔；电阻输出通过内部导电片接 LED，移除虚构的高拱短接线。电位器三脚分占三排。
- LED/RGB 与电位器同时存在时，电位器地线接到 LED/RGB 地排的另一个空孔，复用公共地。
- 原理图的逻辑串联关系保持不变，3D 跳线只绘制实际需要的外部连线。元件特写包含对应插孔，便于检查落点。
- 新增孔位占用与导通/隔离测试，合计 9 项测试通过；类型检查、生产构建、单文件打包和分发检查通过。此项物理孔位验证覆盖 LED、RGB、电阻和电位器，其他器件尚未逐一重做落孔验证。

## 元件悬停、选中与说明卡片

- 悬停进入元件时执行一次 520 ms 的轻跳，并显示名称和圆环提示；退出、点击、切课时归位，减弱动画设置下不跳动。拾取悬停时使用静止位置，避免模型跳动导致反复触发。
- 点击显示选中圆环、标记和指向说明卡片的虚线；不立即放大，仅在卡片遮挡目标时平移让开。通过「放大查看」单独进入特写，关闭卡片/切课清理选中状态。
- 板载模组、PCB 天线、USB、USB 转串口芯片、稳压器、供电灯、按钮、电阻/电容、38 个排针，以及面包板、外接器件均有独立拾取和说明。模型中的小型被动器件说明以功能教学为目的，不将示意编号作为实物 PCB 位号。
- GPIO 说明展示本课连接与对应功能；重复 GND 排针仍可独立选中。RGB 三只限流电阻分别对应原理图中的 R/G/B 通道，避免点击任意电阻都打开整个 RGB LED。
- 板载及引脚说明参考 [Espressif ESP32-DevKitC V4 官方指南](https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32/esp32-devkitc/user_guide.html)。
- 验证：10 项测试通过；浏览器验证真实模型悬停/点击、独立芯片说明、单独放大、切课清理和 RGB 三路电阻与原理图双向选中；实际拖动旋钮从 50% 更新为 86%。窄窗口按说明卡片周围可用空间避让，避免将元件挤到顶部。
