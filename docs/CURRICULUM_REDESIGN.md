## 每课的完整链路

操作场景元件 → 改变同一份课程输入 → 模拟状态更新 → 3D/原理图/显示与串口反馈。代码参数来自同一份输入；复制到 ESP32 的示例实现同课输入输出规则。浏览器是教学模型，不把动画当作硬件已测试。

- 概览说明要做什么、如何操作、应该观察到什么；每课只突出少量新概念。
- 引脚图对应真实 ESP32 接线；所有模拟输入遵循 3.3 V 电气条件。
- 示例解释本课关键代码与操作现象的关系；规格保留量程、供电和模型简化说明。
- 植物的自然变干、手动浇水属于环境输入；硬件代码读取实际土壤传感器，不伪造自动浇水执行器。
- 光敏课只展示原始读数/相对亮度，未经标定不声称真实照度；植物湿度使用干湿标定，未经实测不声称绝对含水率。
- 新器件具备模型、点击说明、参数、接线、原理图和示例；不只替换标题和文案。

## 实施与基本验证

同步课程定义、模拟行为、3D 场景、代码、接线、课程插图、说明和 README 课程目录。沿用已确认的悬停/选中/卡片、原理图双向联动和右栏展开交互。

类型与构建检查；针对新增/改变的因果关系做必要测试；浏览器验收旋钮调光、光控阈值、琴键、植物干燥/浇水以及联网植物的关键路径。固件仅编译发生逻辑修改的课程，沿用既有工具链；大规模跨浏览器或真机测试另行确定范围。
