## 1. 认识 ESP32

一块小小的开发板，把程序和真实世界连接起来。认识 ESP32 的 USB、模组、引脚和两个按键，看看你的程序从哪里开始。

动手观察：

- 点击开发板上的元件了解用途
- 拖动平移，Q / E 旋转，滚轮缩放
- EN 复位；BOOT 用于进入下载模式

代码与现象：

1. 先点击 USB、模组和电源端，确认程序、供电和引脚分别在哪里。
2. 运行后，setup() 输出 ESP32 ready；loop() 每秒输出一次计数。
3. 点击 EN 再复位程序，对照日志从头开始的现象。
4. 真机选择 ESP32 Dev Module，串口 115200；BOOT 用于下载模式，不是普通实验按钮。

接线：

- 3V3 → 3.3 V 电源
- GND → 公共地

参数：

无额外参数。

规格与模型边界：

- 开发板 / Board：ESP32-DevKitC V4 · WROOM-32E
- 逻辑电平 / Logic：3.3 V
- 框架 / Framework：Arduino-ESP32 3.3.12
- 串口 / Serial：115200 baud

## 2. 让 LED 闪烁

从一颗 LED 开始：GPIO23 通过限流电阻控制灯的亮灭。改变等待时间，灯就会按照不同的节奏闪烁。

动手观察：

- 点击 LED 改变颜色和亮灭时间
- 点击电阻比较不同阻值
- 代码中的数字也可以点击修改

代码与现象：

1. digitalWrite(23, HIGH) 点亮外接 LED，LOW 使它熄灭。
2. 亮灯 500 ms、灭灯 500 ms，加起来是 1 秒；先只改其中一个等待时间。
3. 颜色与电阻改变电路的表现；代码里的 GPIO23 和限流接法保持一致。
4. 串口同步输出 GPIO23 电平，帮你把程序与亮灭现象对上。

接线：

- GPIO23 → 电阻 → LED 阳极

参数：

| 参数 | 默认值 | 范围 / 选项 |
| --- | --- | --- |
| 亮灯 | 500 ms | 50–2000 ms |
| 灭灯 | 500 ms | 50–2000 ms |
| 颜色 | #df554b | 红色 / 黄色 / 绿色 / 蓝色 / 白色 |
| 电阻 | 330 | 220 Ω / 330 Ω / 1 kΩ |

规格与模型边界：

- 引脚 / Pin：GPIO23 → 330 Ω → LED → GND
- 逻辑电平 / Logic：3.3 V
- 电流 / Current：约 (3.3 − Vf) / R，理想估算

## 3. 按下按钮

输入让开发板感知你的动作。按钮接在 GPIO27 和 GND 之间，内部上拉让松开时为 HIGH，按下时为 LOW。

动手观察：

- 按住场景中的按钮，再松开
- 观察输入电平、LED 和串口一起变化
- 切换逻辑，让按下时熄灯

代码与现象：

1. INPUT_PULLUP 让松开的按钮读为 HIGH，按下接 GND 后读为 LOW。
2. pressed = digitalRead(27) == LOW 把电平变成“是否按下”的布尔值。
3. 先按住、松开，再切换控制方式：输入没变，if 判断后的输出变了。

接线：

- GPIO23 → 电阻 → LED 阳极
- GPIO27 → 按钮 → GND（内部上拉）

参数：

| 参数 | 默认值 | 范围 / 选项 |
| --- | --- | --- |
| 控制方式 | 0 | 按住亮 / 按住灭 |

规格与模型边界：

- 输入 / Input：GPIO27 · INPUT_PULLUP
- 按下 / Pressed：LOW
- 输出 / Output：GPIO23

## 4. 旋钮调光

把旋钮当作调光开关：从左转到右，LED 由暗变亮。GPIO34 先把旋钮电压读成 0–4095，再把它换算成 0–255 的亮度。试着找出半亮时的读数。

动手观察：

- 运行后拖动旋钮，观察 LED 从暗到亮
- 对照 ADC 0–4095 与 PWM 0–255
- 把旋钮转到两端，再找到半亮的位置

代码与现象：

1. 电位器两端接 3V3/GND，中间脚接 GPIO34；拖动旋钮改变输入电压。
2. analogRead(34) 返回 0–4095 的 12 位原始值，map 将它换成 0–255。
3. ledcAttach(23, 5000, 8) 配置 PWM；ledcWrite 设置亮度，数值越大，LED 平均发光越强。
4. 先找全暗、全亮，再找 PWM≈128。模型在约 3.1 V 饱和，因此全亮可能早于旋钮转到最右端；真实 ADC 需要标定。

接线：

- GPIO34 → 电位器中间脚（ADC1）
- GPIO23 → 电阻 → LED 阳极

参数：

| 参数 | 默认值 | 范围 / 选项 |
| --- | --- | --- |
| 旋钮位置 | 50 % | 0–100 % |

规格与模型边界：

- 电位器 / Potentiometer：10 kΩ · 3V3 / GND
- ADC：12 bit · ADC1 GPIO34
- PWM：GPIO23 · 5 kHz · 8 bit
- 模型 / Model：理想化 0–3.1 V → 0–4095
- 实际 / Hardware：11 dB 有效量程约 150–3100 mV

## 5. 混合颜色

调出你喜欢的灯光颜色。先只开红灯，再加入绿色，看看怎样变成黄色；试着调出紫色和白色。三个 PWM 通道分别控制红、绿、蓝的亮度。

动手观察：

- 先只打开红色，再逐个混入绿色、蓝色
- 试着调出黄色、紫色和白色
- 比较单路亮度与混合后的颜色

代码与现象：

1. 先把绿色、蓝色设为 0，只看红色通道。
2. 增加绿色得到黄色；增加蓝色得到紫色；三个通道一起发光得到混合色。
3. 三个 ledcWrite 分别控制 GPIO23/19/18，每路有独立的 330 Ω 电阻。
4. 255 是 PWM 占空比计数，不是 255 V，也不是电流值。

接线：

- GPIO23 → 电阻 → RGB 红色
- GPIO19 → 电阻 → RGB 绿色
- GPIO18 → 电阻 → RGB 蓝色

参数：

| 参数 | 默认值 | 范围 / 选项 |
| --- | --- | --- |
| 红色 | 255 | 0–255 |
| 绿色 | 80 | 0–255 |
| 蓝色 | 20 | 0–255 |

规格与模型边界：

- PWM：5 kHz · 8 bit · 0–255
- RGB：共阴极 / Common cathode
- API：ledcAttach(pin, 5000, 8)

## 6. 光控夜灯

让一盏灯自己判断天黑。拖动台灯上的亮度滑块：环境变暗时 LED 自动亮起，变亮时熄灭。光敏电阻和 10 kΩ 电阻组成分压，让 ESP32 看见光的变化。

动手观察：

- 调暗台灯，让夜灯自动亮起
- 移动阈值，改变开灯时刻
- 对照光线、GPIO34 读数和 if 判断

代码与现象：

1. 分压接法是 3V3 → 光敏电阻 → GPIO34 → 10 kΩ → GND。固定电阻必须接到 GND。
2. 光越亮，光敏电阻阻值越低，GPIO34 的电压与原始读数越高。
3. if (light < threshold) 把“读数较低”解释为天黑，点亮 GPIO23 的夜灯。
4. 先调暗台灯，再改变阈值，验证相同光线能否得到不同的开灯决定；本课显示相对亮度，不是 lux。

接线：

- GPIO34 → 光敏分压输出（ADC1）
- GPIO23 → 电阻 → LED 阳极

光敏模块内部：3V3 → LDR → GPIO34 → 10 kΩ → GND。台灯是环境输入，无电气连线。

参数：

| 参数 | 默认值 | 范围 / 选项 |
| --- | --- | --- |
| 台灯亮度 | 75 % | 0–100 % |
| 开灯阈值 | 1800 ADC | 100–3900 ADC |

规格与模型边界：

- 分压 / Divider：3V3 → LDR → GPIO34 → 10 kΩ → GND
- ADC：12 bit · ADC1 GPIO34
- 读数 / Reading：越亮越高 / Higher in brighter light
- 范围 / Scope：相对亮度，未经照度标定 / Relative light, not lux

## 7. 温度报警器

做一个会提醒你的温度计。升温超过设定值，红灯亮起、蜂鸣器鸣叫；降温后恢复安静。先体验触发点，再看 TMP36 怎样把温度变成电压。

动手观察：

- 把温度升过阈值，观察红灯与鸣叫
- 降低温度，让报警停止
- 移动阈值，比较触发点如何变化

代码与现象：

1. TMP36 在 0 °C 输出 500 mV，每升高 1 °C 增加 10 mV；25 °C 对应约 750 mV。
2. analogReadMilliVolts(35) 返回校准毫伏，减 500 再除 10 得到温度。
3. temperatureC >= threshold 时点亮 LED；每秒前 100 ms 发出提示音。
4. 升温越过阈值，再降到阈值以下；移动阈值重做一遍，比较输入、判断和输出。

接线：

- GPIO35 → TMP36 输出（ADC1）
- GPIO23 → 电阻 → LED 阳极
- GPIO25 → 无源压电蜂鸣片

参数：

| 参数 | 默认值 | 范围 / 选项 |
| --- | --- | --- |
| 环境温度 | 25 °C | 0–60 °C |
| 告警阈值 | 30 °C | 10–50 °C |

规格与模型边界：

- TMP36：3.3 V · 10 mV/°C
- 输出 / Output：500 mV at 0 °C
- 输入 / Input：GPIO35 · ADC1
- 模型 / Model：不含噪声与器件误差 / Ideal model

## 8. 让 OLED 显示数据

让温度计自己报数。在 OLED 上显示温度和进度条，改变温度，看看下一次刷新。把刷新间隔调慢，再调快，比较画面跟上变化的速度。

动手观察：

- 放大 OLED，改变温度看数字和温度条
- 把刷新间隔调到 2 秒，观察显示的延迟
- 恢复 100 ms，比较屏幕更新的节奏

代码与现象：

1. 四根线分别是 3V3、GND、GPIO21 SDA 和 GPIO22 SCL。
2. 程序先把文字和矩形画到内存，display.display() 再把整幅画面送给屏幕。
3. 温度条把 0–60 °C 映射为条形宽度；改变温度，观察下次刷新。
4. 把间隔改为 2000 ms，看显示暂时保持旧值；改回 100 ms，看更新更及时。真机先确认 I²C 地址与库。

接线：

- GPIO21 → OLED SDA
- GPIO22 → OLED SCL
- GPIO35 → TMP36 输出（ADC1）

OLED 用 3.3 V 供电和上拉，SDA21/SCL22；默认 0x3C，实物先核对地址。

参数：

| 参数 | 默认值 | 范围 / 选项 |
| --- | --- | --- |
| 环境温度 | 25 °C | 0–60 °C |
| 刷新间隔 | 500 ms | 100–2000 ms |

规格与模型边界：

- OLED：SSD1306 · 128 × 64 · I²C
- 地址 / Address：0x3C（实际模块先扫描）
- 接线 / Pins：SDA21 · SCL22 · 3.3 V

## 9. 迷你钢琴

八个琴键，一个蜂鸣器，弹出你的第一段旋律。按住场景里的琴键就发声，松开就安静；也可以用键盘 1–8。把音区升高一个八度，听听频率翻倍的变化。

动手观察：

- 按住 Do 到 Do↑，听完整音阶
- 试着弹 Do Do Sol Sol La La Sol
- 切换八度，比较频率和音高

代码与现象：

1. 八个琴键使用 GPIO13/14/16/17/18/19/26/27 的内部上拉；按下为 LOW。
2. KEYS 和 NOTES 两个数组按相同顺序排列；按键编号找到对应的音符频率。
3. 只有按下或松开状态改变时才切换音调，松开后 ledcWriteTone(25, 0) 静音。
4. Do 约 262 Hz；把八度乘数从 1 改为 2，频率翻倍。多键同时按下时，编号最大的键优先。

接线：

- GPIO13 → Do 琴键（内部上拉）
- GPIO14 → Re 琴键（内部上拉）
- GPIO16 → Mi 琴键（内部上拉）
- GPIO17 → Fa 琴键（内部上拉）
- GPIO18 → Sol 琴键（内部上拉）
- GPIO19 → La 琴键（内部上拉）
- GPIO26 → Si 琴键（内部上拉）
- GPIO27 → Do↑ 琴键（内部上拉）
- GPIO25 → 无源压电蜂鸣片

琴键模块内部各键分别接输入与公共 GND，使用内部上拉；未使用 GPIO6–11、启动配置脚或输入专用脚作键盘上拉输入。多键同时按下时，编号最大的键优先。

参数：

| 参数 | 默认值 | 范围 / 选项 |
| --- | --- | --- |
| 音区 | 1 | C4–C5 · 中音 / C5–C6 · 高八度 |

规格与模型边界：

- 琴键 / Keys：8 · INPUT_PULLUP · 按下 LOW
- GPIO：13 / 14 / 16 / 17 / 18 / 19 / 26 / 27
- 音区 / Notes：C4–C5 / C5–C6
- 输出 / Sound：GPIO25 · ledcWriteTone
- 同时按键 / Priority：编号最大的按下琴键 / Highest pressed index

## 10. 转动舵机

让一根指针听你的指挥。拖动舵机指针，或把脉宽从 1500 µs 向两侧调整，看它怎样转动。控制位置的是每个 20 ms 周期里的高电平时长。

动手观察：

- 拖动指针，或调节脉宽
- 1500 µs 是课程模型的中位
- 舵机单独供电，并与 ESP32 共地

代码与现象：

1. 舵机的电源来自独立稳压 5 V，并与 ESP32 共地；信号接 GPIO18。
2. 50 Hz 对应 20 ms 周期，脉宽 1000–2000 µs 映射到课程中的指针行程。
3. 先用 1500 µs 找中位，再慢慢往两侧移动；LED 调光的占空比不能直接当作舵机角度。
4. 实际舵机的机械端点与脉宽需按型号标定。

接线：

- GPIO18 → 舵机信号

舵机采用独立稳压 5 V，与 ESP32 共地。

参数：

| 参数 | 默认值 | 范围 / 选项 |
| --- | --- | --- |
| 脉宽 | 1500 µs | 1000–2000 µs |

规格与模型边界：

- 周期 / Period：20 ms · 50 Hz
- 脉宽 / Pulse：1000–2000 µs
- 供电 / Supply：独立稳压 5 V，共地
- 角度 / Angle：实际行程需标定 / Calibrate hardware

## 11. 智能植物

植物会用屏幕告诉你它的感受。等土壤慢慢变干，OLED 出现 Water me!，再按住洒水壶给它浇水。读数、湿度条和叶片一起变化；水浇得太多，也会提醒你。

动手观察：

- 按住洒水壶，让缺水的植物恢复
- 改到阳光下，观察土壤更快变干
- 调干湿标定，理解相对湿度怎样算出

代码与现象：

1. 先运行，等土壤变干；把位置换到阳光下，可更快看到 Water me!。
2. 按住洒水壶是给环境加水，程序只负责读取传感器和显示；没有控制水泵。
3. 传感器越湿读数越低。map(raw, DRY, WET, 0, 100) 把实测干湿两点换为相对百分比，再 constrain 到 0–100。
4. 超过过湿阈值显示 Too wet!。调标定值只改变读数的解释，不改变土壤本身；实物需要测自己的 DRY/WET。

接线：

- GPIO34 → 土壤传感器 AOUT（ADC1）
- GPIO21 → OLED SDA
- GPIO22 → OLED SCL

土壤传感器 VCC 接 3V3、GND 共地；植物和洒水壶属于环境，不画成 GPIO 执行器。湿度百分比是干湿标定范围内的相对值；固定环境模型示例原始读数约为干燥 3300、湿润 1400，修改标定只改变程序对读数的解释。

OLED 用 3.3 V 供电和上拉，SDA21/SCL22；默认 0x3C，实物先核对地址。

参数：

| 参数 | 默认值 | 范围 / 选项 |
| --- | --- | --- |
| 土壤湿润程度 | 55 % | 0–100 % |

## 17. 测量障碍物距离

给机器人一双感知距离的眼睛。拖近障碍物，看看超声波往返时间怎样变短；超过停车线时 LED 提醒，再试一次没有回波的情况。

- 拖动障碍物，比较厘米与回波时间
- 改变停车距离，观察 LED 提示

代码与现象：

1. 运行后拖动障碍物。TRIG 发出 10 µs 脉冲，ECHO 高电平的时长表示声波往返时间。

- 测距 / Distance：echoµs × 0.0343 / 2 cm；超时记为无效，不是 0 cm

1. 令角速度为 0，两个轮子的目标线速度相同，机器人直行。
2. 轮距为 L：vL = v − ωL/2，vR = v + ωL/2；再用 RPM = v轮 × 60 / (2πr) 转换目标。
3. 线速度设为 0、角速度保持正数，左右轮反向，机器人原地转动；超过轮速上限时按同一比例缩小左右目标，保持曲率。
4. 左右轮各有独立 PI。场景位移使用编码器实测轮速积分；真机里程计会因打滑和轮径误差漂移，并不等于外部定位。

规格与模型边界：

- 驱动 / Driver：TB6612FNG · VCC 3.3 V · STBY GPIO4
- 电机 / Motor：额定 6 V 编码器减速电机 · 课堂独立 5 V 供电并共地
- PWM：20 kHz · 8 bit · −255…255
- 功率 / Power：电机堵转电流须低于驱动器额定值；GPIO 不给电机供电
- 编码器 / Encoder：A 相上升沿计数，B 相判向 / A rising edge, B direction
- 采样 / Sample：100 ms · RPM = Δcount × 60 / (CPR × Δt)
- CPR：轮轴计数示例 360，真机按减速比与计数方式标定
- 右编码器 / Right encoder：本课 3.3 V 推挽输出直连；GPIO34/35 无内部上拉，开集电极型号另需上拉
- 闭环 / Control：两轮独立 PI · 100 ms · 带输出饱和与积分限制
- 指令 / Command：SET,<leftRPM>,<rightRPM> 或 STOP
- 范围 / Range：−150…150 RPM
- 状态 / State：回传目标与编码器实测转速 / Target and measured RPM
- 时效 / Freshness：首次合法命令前静止；1000 ms 未收合法命令停车
- 感知 / Sensing：HC-SR04 · ECHO 分压到约 3.0 V；100 ms测距
- 调度 / Scheduling：100 ms测距与PI；200 ms状态回报；UART持续解析
- 停车 / Stop：距离低于阈值、无回波、STOP 或指令过期均清除目标
