# ESP32 课程内容 v0.2

日期：2026-10-24。16 课内容适配 ESP32；所有页面继续使用原站的概览、引脚图、示例、规格四个页签。课程主题可以与原站不同，交互框架保持一致。

当前只有内容计划，尚未实现课程场景或编译代码。每课的操作说明是实验交互定义，不是新增的任务考核流程。

## 1. 共同约定

- 板型：ESP32-DevKitC V4，ESP32-WROOM-32E，38 针。
- 代码：Arduino C++，Core 3.3.12；串口 115200 baud。
- 使用 GPIO 编号和板上丝印，不沿用 Uno 的 D13、A0 或 PWM 专用脚规则。
- 固定引脚是课程默认值；只有明确提供引脚选择的课程才显示选择器，不能因框架支持就增加控件。
- 参数通过检查器和代码数值入口修改，运行反馈出现在原有场景、代码、串口和读数区域。
- 学习进度沿用原站运行完成标记，不设答题或变化题门槛。
- 实际器件误差和教学模型的范围放在现有规格或示例页签说明，不新增合规或验证面板。

## 3. 每课内容与交互

### 01 认识 ESP32

- 概览：芯片、模组与开发板的关系；setup/loop、启动与复位。
- 引脚图：3V3、GND、EN、BOOT、GPIO、电源及输入专用脚；按官方 38 针布局显示。
- 示例：启动串口日志的最小程序，介绍编译和烧录的实际含义。
- 规格：ESP32-WROOM-32E、接口和供电条件。
- 场景交互：旋转/平移/缩放、热点检查、聚焦器件、EN 复位演示，运行后出现模拟启动日志。
- 适配：官方板电源灯不是可控 LED；本课不把 LED_BUILTIN 当统一可用的引脚。

### 02 点亮 LED

- 概览：数字输出、LED 极性、限流和亮灭周期。
- 引脚图：GPIO23 → 电阻 → 红色 LED → GND。
- 示例：pinMode、digitalWrite、delay 和亮灭时长。
- 规格：3.3 V 逻辑；默认 330 Ω，提供 220/330/1000 Ω 选项，电流为带假设的估算。
- 场景交互：点击 LED 或代码时长打开检查器，改变颜色、亮/灭时间；点击电阻换阻值，运行中实时反馈。
- 适配：默认引脚改为 GPIO23；不沿用 Uno 的 5 V 电流计算。

### 03 查看串口输出

- 概览：串口速率、文本与变量、状态日志。
- 引脚图：沿用 GPIO23 LED 和 USB 串口。
- 示例：Serial.begin、print/printf、计数递增，每次 LED 翻转输出一条记录。
- 规格：115200 baud，说明模拟时间和实际串口的区别。
- 场景交互：调 LED 翻转/日志间隔，运行、停止，查看串口面板和对应代码区域。
- 适配：USB-UART 说明使用 ESP32 板型，GPIO1/3 保留串口用途。

### 04 按下按钮

- 概览：数字输入、上拉和低电平有效。
- 引脚图：GPIO27 与 GND 之间接按钮，INPUT_PULLUP；GPIO23 接 LED。
- 示例：digitalRead 和 if/else；提供按住亮和反向电平两种逻辑参数。
- 规格：输入浮空与内部上拉说明。
- 场景交互：按住、松开按钮；输入电平、灯和日志同步变化，检查器切换逻辑。
- 适配：GPIO27 按下为 LOW；本课不引入切换灯状态所需的边沿和消抖逻辑。

### 05 转动旋钮

- 概览：电位器分压与 ADC 数字化。
- 引脚图：10 kΩ 电位器两端接 3V3/GND，滑动端接 GPIO34（ADC1）。
- 示例：analogRead、12 位分辨率、衰减和原始值输出。
- 规格：0—4095 原始值；11 dB 衰减的测量范围说明。
- 场景交互：拖动旋钮、检查器调比例，电压、模拟读数、代码和串口联动。
- 适配：课程理想模型 raw = round(clamp(V/3.1,0,1) × 4095)，V = 3.3 × 旋钮比例。该模型只表达量化与饱和，不拟合真实 ADC；不把 4095 解释成精确 3.3 V。

### 06 调光与混合颜色

- 概览：PWM、占空比、数值映射、RGB 三通道。
- 引脚图：单 LED 用 GPIO23；RGB 共阴 R/G/B 对应 GPIO23/19/18，各自串电阻。
- 示例：ledcAttach、ledcWrite，5 kHz/8 位；旋钮输入映射输出计数。
- 规格：0—255 输出计数；RGB 与单 LED 为独立预设场景。
- 场景交互：点击灯切场景或颜色通道，滑块调占空比，旋钮驱动亮度，观察波形与灯光。
- 适配：使用 Arduino-ESP32 3.x 的 pin API；128/255 约为 50%，视觉亮度不作为光学实测。

### 07 感知温度

- 概览：电压、校准毫伏与温度的关系。
- 引脚图：TMP36 由 3V3 供电，输出接 GPIO35（ADC1），GPIO23 接 LED。
- 示例：analogReadMilliVolts，温度 =（毫伏 − 500）/10；温度达到阈值时亮灯。
- 规格：TMP36 10 mV/°C 与 500 mV 偏置，按 TO-92 数据手册说明脚序。
- 场景交互：温度滑块 0—60 °C、阈值 10—50 °C，读数、LED、串口和代码联动。
- 适配：不用 Uno 的原始值乘 5/1023 换算；在规格说明实际传感器与 ADC 误差。

### 08 非阻塞控制

- 概览：millis 和多个周期任务。
- 引脚图：GPIO23 LED、GPIO27 按钮、GPIO34 电位器。
- 示例：无符号差值计时、分别调度翻转和采样，不用长 delay 阻塞按钮。
- 规格：明确翻转间隔和完整亮灭周期的区别。
- 场景交互：调整采样/翻转周期，运行中按按钮、转旋钮，从日志和读数观察独立响应。
- 适配：时间按模型时钟计算，不用浏览器帧数当作单片机时间。

### 09 显示数据

- 概览：I²C、设备地址、显示更新。
- 引脚图：OLED SDA→GPIO21、SCL→GPIO22，3.3 V 供电/上拉；TMP36→GPIO35。
- 示例：Wire、Adafruit SSD1306、GFX，采样温度并更新屏幕。
- 规格：128×64、选定 0x3C 地址版本，实际模块先扫描确认。
- 场景交互：点击 OLED 放大，调刷新周期和显示选项，改变温度后观察屏幕；简化展示 I²C 数据过程。
- 适配：总线数据与电流标注区分；依赖库及 BusIO 在引入时锁定版本。

### 10 发出声音

- 概览：频率、鸣叫时长和间隔。
- 引脚图：适合 GPIO 信号驱动的低负载无源压电蜂鸣片→GPIO25/GND。
- 示例：ledcAttach、ledcWriteTone，millis 控制节奏。
- 规格：选定压电器件的范围，声音开关只影响音频展示。
- 场景交互：点击蜂鸣器调频率和节奏；运行时声音、引脚信号和日志联动。
- 适配：不把电磁蜂鸣器或大功率负载纳入直接 GPIO 驱动示例。

### 11 驱动舵机

- 概览：周期、脉宽与位置控制；执行器供电。
- 引脚图：信号→GPIO18，独立稳压 5 V 供舵机，与 ESP32 共地；ESP32 自身由 USB 供电。
- 示例：50 Hz、16 位 LEDC；脉宽转换成计数。
- 规格：课程控制范围 1000—2000 µs，1500 µs 为模型中位；实物角度按型号标定。
- 场景交互：拖动位置或检查器调脉宽，舵机转动，信号/代码实时更新。
- 适配：不从板上 3V3 给舵机供电，外部 5 V 不接入板上供电脚。

### 12 组合告警

- 概览：NORMAL、ALARM、ACK 和稳定按下事件。
- 引脚图：TMP36→35、按钮→27、LED→23、压电蜂鸣片→25。
- 示例：enum/switch、millis 消抖；阈值以上告警，确认后静音，降温复位。
- 规格：稳定 30 ms 后产生按下事件；阈值 10—50 °C。
- 场景交互：调温、按键确认、调节阈值，在现有读数和串口观察状态与输出，不增加任务面板。
- 适配：低电平按键、ADC1 和 LEDC 音调；状态优先级在技术路线中统一定义。

### 13 连接 Wi-Fi

- 概览：STA、2.4 GHz、SSID、连接阶段、设备 IP。
- 引脚图：ESP32 与路由器的数据关系示意，无新增外设接线。
- 示例：WiFi.mode/begin/status/localIP；本地填写网络配置的真实代码用法。
- 规格：经典 ESP32 的无线能力；站内连接过程为教学模拟。
- 场景交互：点击路由器热点进入检查器，切换课堂网络场景；运行后从串口和场景观察连接阶段。
- 适配：不扫描电脑 Wi-Fi、不收集家庭密码，不添加新的网络设置向导。

### 14 读取 HTTP 数据

- 概览：ESP32 提供 HTTP 服务，客户端请求路径后取得 JSON。
- 引脚图：沿用 TMP36→GPIO35，另展示浏览器到 ESP32 的数据路径。
- 示例：内置 WebServer，GET /api/state 返回设备状态，未知路径返回 404。
- 规格：方法、路径、响应状态、字段和单位。
- 场景交互：浏览器对象的检查器选择预设路径；运行中触发请求，在串口和读数区显示响应。
- 适配：不另建请求实验平台；代码和协议说明放在原有示例页签。

### 15 用网页控制

- 概览：网页按钮、设备执行和状态回读。
- 引脚图：GPIO23 LED，ESP32 与浏览器的数据关系。
- 示例：设备提供 GET / 页面、POST /api/led 控制接口、GET /api/state 回读接口。
- 规格：value=0/1 表单编码控制，JSON 响应；不合法参数返回 400。
- 场景交互：浏览器对象检查器保留元件式操作方式，开/关灯后观察 3D LED、串口及设备状态。
- 适配：真机页面由 ESP32 提供，同源相对路径请求；教学站不跨域控制局域网硬件。

### 16 综合项目

- 概览：联网温度监测与告警器，输入、处理与输出组合。
- 引脚图：TMP36→35、按钮→27、LED→23、蜂鸣片→25、OLED→21/22。
- 示例：200 ms 温度采样、500 ms OLED 刷新；每轮处理按钮和网络；网页阈值设置与状态回读。
- 规格：0—60 °C 教学温度输入，10—50 °C 整数阈值；默认 25 °C/30 °C。
- 场景交互：按原有方式点击传感器、按钮、OLED 和浏览器对象，修改输入/参数，观察所有输出联动。
- 适配：ADC1 与 Wi-Fi 同用，保持单一告警状态；开发者维护相应可编译工程，不增加用户考核或下载流程。
