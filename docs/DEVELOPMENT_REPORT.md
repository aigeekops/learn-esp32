## 已实现

Vite、TypeScript、Three.js 独立实现了原站式工作台。16 课均具备概览、引脚图、示例、规格、对应元件场景和 Arduino C++ 模板。参数是检查器、代码和教学行为模型的共同输入；接线端点是 3D、引脚表及 SVG 的共同来源。

没有新增任务提交、考核门槛、AI 助教、账户、云同步、自由接线、任意代码执行或浏览器烧录。

## 剩余差异与证据边界

1. **视觉复刻仍需细调**：程序化 ESP32/元件模型、图标、纸面背景、相机运动和弹层细节经过代表状态对照，尚未做逐像素或逐动画验收。
2. **翻译未完成**：中文课程完整；英文包含课程标题、说明、参数与操作说明。其余 11 种语言目前覆盖常用界面文字，课程正文仍显示英文，不能称为 13 语种全文完成。
3. **模拟是参数化教学模型**：不执行复制出的任意 C++；ADC 不含噪声/误差，面包板孔位不计算导通；网络只演示本地模型的状态和请求。固件与模型的采样时序已核对关键路径，不宣称所有执行时刻完全等价。
4. **未做真机验证**：未烧录 ESP32，未测量 GPIO/ADC/PWM、舵机端点、OLED 地址、电源负载、无线连接或真实 HTTP。固件编译通过只证明代码能通过所选工具链。
5. **未做大规模测试**：没有跨浏览器矩阵、真实移动设备测试、性能压测、参数穷举或完整截图回归。生产包内 Three.js 使单个 JS 超过 Vite 的 500 kB 提示阈值；构建成功。

默认代码和逐课日志可通过 README 中的命令生成到 `output/sketches/` 与 `output/compile/`；它们不提交 Git。首次编译摘要保存在 `docs/validation/2026-10-24-firmware.json`，不代表后续改动已经重新编译。应用源码、模型、卡片插图和 SVG 均为本项目实现，未引入参考站构建文件或模型素材。
