# 交互复刻清单 v0.2

日期：2026-10-24。用途：约束实现与验收，不代表下列功能已经完成。

## 1. 对照原则

- 使用同尺寸视口、同类课程状态和同一操作顺序对照原站。
- 必要内容变化只包括 ESP32 及其课程带来的模型、接线、参数、文字和代码变化。
- 不新增学习步骤、考核按钮、完成门槛和独立实验平台。
- 本清单根据已观察界面及公开脚本建立；动画细节、弹层关闭条件和响应式断点在 M1 对照记录中锁定，不假定已全量核查。

## 2. 操作与反馈

| 编号 | 操作 | 保持的反馈与行为 |
| --- | --- | --- |

## 3. 已确认的设置项

公开脚本包含：标注、电流流动、地面网格、空闲旋转、声音、减弱动画，以及重置进度。原理图开关另由工具栏控制。默认值和具体文案在 M1 对照原站复核。

不将设置改为课程难度、闯关模式或教学目标配置。

## 4. 参数运行规则

原站运行时会读取当前参数。复刻站在检查器调参时保留实时反馈，不把全部参数修改统一改为停止、重置并重新运行。

具体参数是否重置局部状态取决于该实验：例如亮灭时间更新后继续按新节奏运行；切换实验模式所需的局部状态清理由模型明确处理。代码内容随参数更新，但这种映射不代表浏览器正在编译任意 C++。

环境输入也在同一交互框架中处理：按键、旋钮、温度和网络场景通过元件操作或检查器改变；不增加统一的任务提交按钮。

## 5. 基本对照记录要求

M1 记录原站及复刻站在桌面、手机两个视口下的：默认工作台、元件检查器、运行和串口、原理图、设置菜单等代表状态。记录每条操作的入口、状态变化和偏差。

课程内容不同的部分依据本项目课程定义核对。视觉与交互相同的部分依据原站核对。尚未复核的细节列入偏差清单，不宣称已达到完全一致。
